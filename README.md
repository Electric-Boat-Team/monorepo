# Electric Boat Team Monorepo

Private monorepo for Electric Boat Team.

## Layout

- `packages/` — shared packages and services

## Contributing

All changes land via pull request. `main` is protected:

- Pull requests required, no direct pushes
- At least one approval from someone other than the PR author
- Stale approvals are dismissed when new commits are pushed
- Force pushes and branch deletions are blocked
